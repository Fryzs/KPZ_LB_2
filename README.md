# Піцерії — патерн «Фабричний метод»

Лабораторна робота №2 з КПЗ на Windows Forms (.NET), що демонструє патерн **Factory Method**.

## Як працює

Абстрактна `Pizzeria` оголошує фабричний метод `CreatePizza()`, а кожна з трьох піцерій реалізує його по-своєму:

| Піцерія | Піца | Тісто | Соус | Ціна |
|---------|------|-------|------|------|
| Перша | Маргарита | тонке | томатний | 150 грн |
| Друга | Пепероні | товсте | гострий томатний | 180 грн |
| Третя | Гавайська | пухке | солодкий | 200 грн |

Натисніть кнопку піцерії — на формі з'явиться опис піци, яку вона «приготувала».

## Запуск

Відкрийте `KPZ_LB_2.sln` у Visual Studio і натисніть F5.
